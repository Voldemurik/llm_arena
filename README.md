## О проекте

Agent Evaluation Lab — учебный симулятор для наглядного сравнения трёх стратегий работы агента: прямого ответа (`direct`), предварительного планирования (`plan`) и планирования с проверкой результата (`verify`).

Сайт позволяет:

- запускать сценарии на выбранном наборе задач и наблюдать журнал работы агента;
- сравнивать долю решённых задач, условную стоимость, время и число шагов;
- изучать итоговые карточки сравнения стратегий;
- фильтровать события журнала, раскрывать их с клавиатуры, сбрасывать и повторять запуск;
- работать на экранах разной ширины.

**Это учебная симуляция, а не реальный запуск языковых моделей.** Сайт не обращается к API LLM: исходы и показатели предопределены, денежные единицы условные. История хранится только в текущей сессии страницы и после её перезагрузки не сохраняется.

## Структура репозитория

- `site/` — финальная версия интерактивного сайта на основе варианта Claude;
- `research/` — материалы исследования, ответы моделей и результаты их анализа;
- `research/attempts/` — исходные варианты сайтов, полученные в ходе экспериментов.

## Локальный запуск

Для запуска необходимы Node.js и npm. Из корня репозитория выполните:

```bash
cd site
npm ci
npm run dev
```

После запуска откройте в браузере адрес, который выведет Vite.

## Сборка и предпросмотр production-версии

```bash
cd site
npm ci
npm run build
npm run preview
```

Собранные файлы будут помещены в `site/dist/`. Каталоги `node_modules/` и `dist/` не включаются в репозиторий.

## Проверка

Для development- и production-версий в Chrome проверены запуск сценариев, журнал событий, карточки сравнения, фильтры, сброс и повторный запуск, клавиатурное управление и навигационные ссылки. Также проверены предупреждение при сравнении разных наборов задач, повторяемость результатов и адаптивность на ширинах 375, 768, 1024 и 1440 px.
